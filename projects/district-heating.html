District Heating Load Forecasting

Forecasting hourly district-heating demand using Box–Jenkins models with ambient and supply-water temperature as external inputs.

Time Series Box–Jenkins System Identification MATLAB Forecasting

OVERVIEW

Predicting heat demand from temperature data

The project focused on predicting the load of a district heating system in Esbjerg, Denmark. The available dataset contained 5000 hourly observations of district-heating load, ambient air temperature and supply-water temperature.

Two Box–Jenkins models were developed. The first used ambient temperature as the only external input, while the second added supply-water temperature to investigate whether additional system information improved forecasting performance.

01

The Forecasting Problem

District-heating demand varies strongly over time and is influenced by external conditions such as outdoor temperature. The goal was to build a dynamic model capable of predicting future load while accounting for both temporal structure in the load signal and the influence of external temperature inputs.

Engineering challenge

The model needed to capture daily seasonality, short-term dynamics and temperature-driven changes while still generalizing to time periods and seasons that were not used for model estimation.

02

03

Time-Series Analysis

Autocorrelation and partial autocorrelation analysis were used to identify temporal structure in the signals. The ambient temperature displayed strong daily behaviour, motivating seasonal model terms around lag 24.

Similar analysis of the district-heating load showed both short-term dependence and daily seasonality. Candidate model structures were evaluated using residual autocorrelation, input–residual cross-correlation and forecasting performance.

04

Box–Jenkins Modelling

The first model used ambient temperature as an exogenous input. A separate time-series model was first estimated for the temperature so that future temperature values could be predicted during multi-step load forecasting.

y(t) = B(z) / A₂(z) · u(t − d) + C(z) / A₁(z) · e(t)

The transfer-function component models how ambient temperature affects heating load, while the noise model captures dynamics in the load that are not explained by the external input.

Daily seasonality was incorporated using polynomial terms near lag 24. Model parameters were estimated in MATLAB using prediction-error methods, and candidate structures were compared using residual diagnostics and validation forecasts.

05

1-Step & 7-Step Forecasting

The final models were evaluated for both short-term 1-step predictions and more challenging 7-step predictions. Forecasts were compared against a naive persistence predictor.

06

Adding Supply-Water Temperature

The second model added supply-water temperature as an additional external input. In principle this provides more information about the heating system, but it also made the modelling problem considerably more complex.

The supply-water temperature contained changing mean levels and large transitions. Mean removal was therefore introduced before modelling this input, and the final multivariate Box–Jenkins model contained separate transfer functions for the two temperature signals.

Unexpected result

Adding the second input did not improve generalization. The simpler ambient-temperature model performed better across all ranges in the hidden server benchmark.

07

Why More Data Did Not Mean a Better Model

Ambient temperature and supply-water temperature were strongly negatively correlated, with a correlation coefficient of approximately −0.83. This meant that much of the information carried by supply-water temperature was already represented by ambient temperature.

The second input also introduced sharp transitions and changes in mean level. As a result, the additional input increased model complexity without consistently adding useful predictive information.

Key modelling lesson

A more complex model is not automatically a better predictor. Additional variables must provide useful independent information and improve performance on unseen data.

08

Generalization & Limitations

Both models were able to follow the overall dynamics of the heating load, but longer-horizon forecasts struggled with rapid changes in amplitude. The 7-step predictions therefore provided much less improvement over the naive baseline than the 1-step predictions.

Hidden server testing further showed that neither model consistently outperformed the naive predictor on every data range. The ambient-temperature-only model nevertheless generalized better than the more complex two-input model.

09

Key Takeaways

System identification

Used ACF, PACF, cross-correlation and residual analysis to identify dynamic model structures.

Multi-step prediction

Implemented 1-step and 7-step predictors using polynomial division and dynamic filtering.

Model validation

Compared models against naive baselines across validation, test and hidden benchmark data.
